# Contributing to SIP Compass

Thank you for your interest in contributing! This is a Product Management Grad Project MVP.

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Run tests (`npm test`) and lint (`npm run lint`)
5. Commit your changes (`git commit -m "feat: description"`)
6. Push to your branch (`git push origin feature/your-feature`)
7. Open a Pull Request

## Development setup

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Guidelines

- Follow the existing code style
- Add tests for new features
- Keep commits small and focused
- Update documentation when adding new features
