# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.0   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a private issue or contacting the maintainers directly.

Do **not** disclose security issues publicly until they have been reviewed and addressed.

## Environment secrets

Never commit `.env` files or API keys. Copy `.env.example` to `.env.local` for local development and keep secrets out of version control.
